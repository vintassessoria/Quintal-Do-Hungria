# Foto do artista — Hungria

Coloque aqui a **foto recortada (PNG com fundo transparente)** do Hungria:

```
/public/assets/quintal/artist/hungria.png
```

Assim que o arquivo existir com esse nome, ele aparece automaticamente:

- no **hero** (figura principal, dentro da composição 360°);
- pode ser reaproveitado no card grande de "A noite em números" e no tile
  da galeria (ajuste os caminhos nesses componentes se desejar).

Enquanto não houver foto, um **placeholder sofisticado** é exibido — nunca uma
foto aleatória. Não é necessário alterar código: basta adicionar o arquivo.

> Dica: exporte a foto em alta resolução, recorte limpo, de preferência em
> pé/corpo inteiro, iluminação que combine com o pôr do sol quente.
