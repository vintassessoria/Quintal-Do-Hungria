# Galeria — fotos adicionais

Pasta reservada para **fotos extras** do evento/campanha (atmosfera, público,
luzes, arena, bastidores).

Os componentes que usam imagens hoje:
- `components/AtmosphereGallery.jsx`
- `components/ManifestoSection.jsx`
- `components/ExperienceNumbers.jsx`

Para usar uma foto nova, adicione o arquivo aqui e troque o `src` no
componente desejado (ex.: `"/assets/quintal/gallery/publico-01.jpg"`).
Use sempre arquivos otimizados (`.webp`/`.jpg`/`.png`).
